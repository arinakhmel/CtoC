# КОНТЕКСТ

# ІНСТРУКЦІЇ
1. Проаналізуй кожну User Story з наданого списку.
2. Для КОЖНОЇ історії напиши критерії приймання у двох форматах:
   - Варіант А: Чек-лист конкретних бізнес-правил та обмежень (обов'язкові поля, перевірки, початкові статуси).
   - Варіант Б: Сценарії у форматі Given-When-Then (нотація Gherkin).
3. Для формату Gherkin згенеруй РІВНО ТРИ сценарії на кожну історію:
   - 1 сценарій успішного виконання (Happy Path).
   - 2 сценарії для граничних випадків або помилок валідації (Edge Cases / Бізнес-обмеження).
