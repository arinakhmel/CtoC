# ІНСТРУКЦІЇ
1. Обери ОДНУ ключову персону (найважливішу для перевірки головної гіпотези платформи). Обґрунтуй вибір.
2. Визнач «Антиперсону» — профіль користувачів, для яких цей продукт принципово НЕ створюється. Це необхідно для встановлення жорстких меж і запобігання генерації зайвого функціоналу.
3. Змоделюй для ключової персони головний шлях користувача (Happy Path) — лінійний хронологічний ланцюжок дій від першого знайомства з продуктом до отримання фінальної цінності.
4. Опиши цей шлях як лінійний ланцюжок із 4–6 послідовних кроків.
5. Для кожного кроку визнач:
   - Назву кроку.
   - Дію користувача (що він фізично робить).
   - Очікувану реакцію системи.
   - Емоцію або глибинну мотивацію на цьому етапі (соціальну чи емоційну).

# ФОРМАТ ВИВОДУ
1. Обрана ключова персона та коротке обґрунтування.
2. Антиперсона (1-2 речення).
3. Покроковий User Journey (Happy Path) у вигляді нумерованого списку (Крок 1, Крок 2... Крок 6).
