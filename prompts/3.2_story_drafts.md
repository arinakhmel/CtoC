# ІНСТРУКЦІЇ
1. Використовуючи кроки з User Journey як каркас, згенеруй широкий перелік драфтів користувацьких історій для кожного кроку.
2. Базуй історії не лише на функціональних, а й на соціальних та емоційних потребах з VPC.
3. Опрацьовуючи вигоди (Gains), згенеруй фічі, що покривають 4 рівні:
   - Обов'язкові (Must-have): базовий мінімум.
   - Очікувані (Expected): природні вимоги до зручності.
   - Бажані (Desired): приємні бонуси.
   - Неочікувані (Unexpected / Wow-фактори): додаткова інноваційна цінність.
4. Згрупуй згенеровані історії відповідно до кроків User Journey. Враховуй обмеження Антиперсони (не генеруй функціонал для неї).

# ФОРМАТ ВИВОДУ
Список кроків (Крок 1, Крок 2...), під кожним з яких — маркований список драфтів історій. У дужках вказуй, яку саме потребу або тип вигоди (Must-have/Wow-фактор) закриває ця історія.
