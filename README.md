# CtoC 

**CtoC** — це платформа мікрозавдань, де студенти-початківці отримують свій перший комерційний досвід без жорсткої конкуренції.

---

## Проблема
На класичних біржах фрилансу студентам майже неможливо пробитися через жорстку конкуренцію із сеньйорами. Водночас замовники вимагають комерційний досвід, якого в новачків ще немає.

## 💡 Рішення
Платформа мікрозавдань, де немає досвідчених агенцій — **лише початківці**. Бізнес делегує невелику рутину, а студенти отримують перші реальні контракти та рядки в резюме.

## Цікаві фічі
* **Імпорт досягнень:** Автоматичне підтягування проєктів з GitHub, сертифікатів та хакатонів замість класичного портфоліо.
* **Студентська верифікація:** Підтвердження акаунту через університетську пошту для підвищення довіри з боку замовників.
* **AI-асистент:** Допомога новачкам у написанні професійних відгуків (пропоузалів) на завдання.
* **Менторське QA:** Опція для клієнта залучити досвідченого розробника для перевірки коду джуніора перед фінальною здачею.

## Чому це працюватиме
Малий бізнес отримує недорогі руки для технічних мікротасків, а студенти — надвисоку мотивацію зробити перший комерційний проєкт. Цільова аудиторія швидко приводитиме друзів через університетські та профільні ком'юніті.

## Монетизація
1. **Комісія:** Відсоток з успішно завершених контрактів.
2. **Підписка рекрутерів:** Доступ компаніям до бази найкращих новачків для прямого найму в штат.
3. **Пріоритетні таски:** Платне просування термінових завдань у стрічці.
